# نظام استمارة وعضوية الجبهة الشعبية المتحدة (UPF)
### المجلس التنفيذي – جامعة زالنجي

نظام متكامل لإدارة واستقبال استمارات عضوية حركة/جيش تحرير السودان – الجبهة الشعبية المتحدة (UPF)، مبني بتقنيات الويب الحديثة ومتصل بقاعدة بيانات PostgreSQL عبر Supabase ومجهز للنشر المباشر على منصة Railway.

---

## 📁 محتويات المشروع

- `index.html`: الاستمارة العامة المخصصة للأعضاء (الترحيب، 17 حقلاً للبيانات، رفع الصورة مع ضغط تلقائي وحفظها).
- `admin.html`: لوحة إدارة منفصلة ومحمية باسم مستخدم وكلمة مرور (تحتوي على الداشبورد، الرسوم البيانية، جدول الأعضاء، إعدادات Supabase، وتغيير كلمة المرور).
- `schema.sql`: كود إنشاء جدول `members` وسياسات RLS ومناظير الإحصائيات (Views) على PostgreSQL.
- `server.js`: خادم Node.js (Express) خفيف لخدمة الصفحات محلياً وعلى Railway.
- `package.json`: ملف تعريف المشروع والاعتماديات للنشر على Railway.

---

## 🔐 بيانات الدخول الافتراضية للوحة الإدارة

- **رابط لوحة الإدارة:** `/admin` أو `/admin.html`
- **اسم المستخدم الافتراضي:** `admin`
- **كلمة المرور الافتراضية:** `upf@2026`
*(يمكنك تغيير اسم المستخدم وكلمة المرور في أي وقت من قسم "🔑 تغيير كلمة المرور" داخل اللوحة)*

---

## 🚀 خطوات الربط مع قاعدة البيانات (Supabase PostgreSQL)

1. أنشئ حساباً مجانياً على [Supabase](https://supabase.com).
2. أنشئ مشروعاً جديداً (New Project).
3. اذهب إلى **SQL Editor** في لوحة Supabase والصق محتويات ملف `schema.sql` واضغط **Run**.
4. اذهب إلى **Project Settings** ➔ **API**:
   - انسخ **Project URL**
   - انسخ **anon / public key**
5. افتح لوحة الإدارة في مشروعك (`/admin`) واذهب لقسم **⚙️ إعدادات Supabase**، الصق البيانات واضغط **حفظ وتفعيل الاتصال**.

---

## 🚂 النشر على Railway

1. افتح [Railway.com](https://railway.com) وسجل الدخول بحساب GitHub.
2. اضغط **+ New Project** ➔ **Deploy from GitHub repo**.
3. اختر المستودع `drr-for-upf`.
4. سيقوم Railway بالتعرف على خادم Node.js وتشغيل المشروع تلقائياً وتوفير رابط دائم (Domain) لموقعك!
