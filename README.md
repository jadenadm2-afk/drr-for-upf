# نظام استمارة وعضوية الجبهة الشعبية المتحدة (UPF)
### المجلس التنفيذي – جامعة زالنجي

نظام متكامل لإدارة واستقبال استمارات عضوية حركة/جيش تحرير السودان – الجبهة الشعبية المتحدة (UPF)، مبني بتقنيات الويب الحديثة ومتصل مباشرة بقاعدة بيانات **PostgreSQL** عبر محرك **Sequelize ORM** بدون أي وسيط خارجي ومجهز للنشر المباشر على منصة **Railway**.

---

## 📁 محتويات المشروع

- `index.html`: الاستمارة العامة المخصصة للأعضاء (الترحيب، 17 حقلاً للبيانات، رفع الصورة مع ضغط تلقائي وحفظها عبر API).
- `admin.html`: لوحة إدارة منفصلة ومحمية باسم مستخدم وكلمة مرور (تحتوي على الداشبورد، الرسوم البيانية، جدول الأعضاء، إدارة قاعدة بيانات PostgreSQL، وتغيير كلمة المرور).
- `server.js`: خادم Node.js (Express) متصل بقاعدة بيانات PostgreSQL عبر محرك Sequelize ويقوم بمزامنة الجداول تلقائياً.
- `package.json`: ملف تعريف المشروع والاعتماديات للنشر على Railway.

---

## 🔐 بيانات الدخول الافتراضية للوحة الإدارة

- **رابط لوحة الإدارة:** `/admin` أو `/admin.html`
- **اسم المستخدم الافتراضي:** `admin`
- **كلمة المرور الافتراضية:** `upf@2026`
*(يمكنك تغيير اسم المستخدم وكلمة المرور في أي وقت من قسم "🔑 تغيير كلمة المرور" داخل اللوحة)*

---

## 🚀 تشغيل قاعدة بيانات PostgreSQL على Railway (بدون Supabase):

1. في لوحة تحكم مشروعك على **[Railway.com](https://railway.com/)**، اضغط زر **+ New**.
2. اختر **Database** ثم اضغط **Add PostgreSQL**.
3. **انتهى!** بمجرد إضافة PostgreSQL، يقوم Railway تلقائياً بربطها مع خادمك عبر متغير `DATABASE_URL`.
4. يقوم محرك **Sequelize** بإنشاء جدول الأعضاء وحقول الاستمارة تلقائياً عند أول تشغيل، دون الحاجة لكتابة أي كود أو أوامر SQL يدوية!

---

## 🚂 النشر على Railway

1. افتح [Railway.com](https://railway.com) وسجل الدخول بحساب GitHub.
2. اضغط **+ New Project** ➔ **Deploy from GitHub repo**.
3. اختر المستودع `drr-for-upf`.
4. اضغط **+ New** في نفس المشروع ➔ **Database** ➔ **Add PostgreSQL**.
5. من إعدادات الخدمة (Service Settings) ➔ **Networking** ➔ اضغط **Generate Domain** للحصول على رابط موقعك الدائم!
